# Prueba Constructor — Barttolo Bots 0.2.1

Extiende Barttolo Bots para Forge 1.20.1. El Constructor escanea la parcela inmóvil, después camina sobre suelo natural abierto hasta sus tareas. Consulta el README de la raíz del repositorio para alcance y comandos.

Build: Java 17 + Gradle 8.8, ejecutar `./gradlew build -x test`.
