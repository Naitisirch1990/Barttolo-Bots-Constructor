# Constructor 0.3.7 — cualquier ángulo llano

Los trayectos llanos entre A y B se comprueban directamente a cualquier ángulo, hasta el máximo general de 2.000 pasos. El tablero rasterizado es continuo y las barandillas se omiten donde invadirían el corredor. Puede despejar una elevación de bloques normales en el recorrido. Los recorridos oblicuos con desnivel conservan la búsqueda por cuadrícula. Reemplazar JAR con servidor detenido y volver a crear el proyecto que quedó planificando.
